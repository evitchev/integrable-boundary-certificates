## Where the formula comes from

Operator Ht(T) psi = Lambda psi, Ht = H_0(T)(1 + ct_1/T^2 + ...), H_0 = T^n phi(T^-2), theta S = s - T.
Order 1 of the WKB is a total derivative.  Order 2, modulo total derivatives:
    int T_2 dv = (1/24) int [d^2/dLambda^2 (H_2/H_1)] Lambda'^2 dv  -  ct_1 int Lambda/(T^2 H_1) dv.
For Lambda = y^n (1 + y^(n/k)) the Beta integrals give exactly
    int Lambda^(-g-2) Lambda'^2 dv = -(c2/(g+1)) int Lambda^(-g) dv,   c2 = n^2 (k+1)/k,
the same constant that normalises l^2 = c2 (PX^2, pi^2); so the density becomes an ordinary function
of T_0 and Lagrange inversion (second form; its Jacobian is psi_1/(n phi), which cancels the 1/H_1)
gives F1.  The Gamma ratio contributes ct_1 = -((k-1)/24) c2, turning n - 1 into n - k = 4, the
number of non-frozen exponents: each of the four dynamical exponents contributes 1/24.
K = 1 gives PX^2 + pi^2 - 1/6.

Why K^2: psi_1 = 0 is the saddle of [w^(K-1)] phi^nu (it is the branch point of the classical curve),
so D^2 log psi_1 has a double pole at the saddle, worth a factor K; with nu ~ K that is K^2.  The
constant 4 and the Gamma ratio have no such enhancement.  The same counting at loss m (singularity
exponent 1/2 - 3m of the m-th correction, moments of Lambda'^2 of order K^-m) gives K^(2m); it is a
counting argument, tested exactly only at loss 1.
